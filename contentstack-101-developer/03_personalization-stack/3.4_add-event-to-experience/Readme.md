### Adding an Event to an A/B Test Experience

Adding an event to an A/B test experience in **Contentstack** enables you to evaluate the **variant performance** based on **impressions** and **conversions**.

- **Events** act as **metrics** within A/B tests.
- You can add up to **5 events** to each test:

  - **1 Primary Event**
  - **4 Secondary Events**

---

### Creating an event

- Create a new event
- enter event key (eg: click)
  > Note: max no of events per project is 100

### Primary vs. Secondary Metrics

- The **primary metric** is used to **determine the winning variant**.
- The **secondary metrics** offer **additional insights** into user behavior, helping you understand how users interact with different content variants.
