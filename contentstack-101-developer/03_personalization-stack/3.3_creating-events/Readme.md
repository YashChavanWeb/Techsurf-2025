## For A/B Test

### Events: Evaluating Success

- **Capturing and tracking user interactions**
- **Monitoring user actions** such as clicks, video plays, and form submissions.

Personalize allows you to track two main types of events for user interactions:

1. **Impressions**
2. **Conversions**

---

### Impressions

Impressions count how many times users **see specific content** on your website. Each time a user views personalized content, it counts as one unique impression. If a user sees the same content multiple times, it will still be counted only once.

---

### Conversions

A **conversion** is an event that indicates a **positive user action**, such as:

- Adding a product to the cart
- Making a purchase
- Scrolling to the end of a page

Conversions are used in A/B test experiences to evaluate the **effectiveness of a variant**. A higher number of conversions typically signals a **winning variant**.
