### **Audiences**

- **Custom Attributes**: Audiences can be segmented based on custom attributes. These attributes represent specific data points assigned to individual users.
- **Audience Segmentation**: Audiences are used to group and target users based on various segments, allowing for more precise and effective targeting.

---

### **Creating New Audiences**

1. **Name the Audience**: Provide a descriptive name for the audience (e.g., _Luxury_).
2. **Configure Rules**: Define how users are grouped by setting specific conditions for each audience.

   - **Select Attribute**: Choose the custom attribute that will define the segment.
   - **Choose Operator**: Select the operator (e.g., equals, contains, greater than, etc.) to define the condition.
   - **Set Value**: Assign the value that the attribute must meet for users to be included in the audience.
