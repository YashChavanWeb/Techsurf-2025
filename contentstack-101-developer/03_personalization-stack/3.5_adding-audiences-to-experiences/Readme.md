### **Adding Audiences to Segmented Experiences**

1. **Associate Audience with Experience**: You can link an audience to a specific experience by using variants.
2. **Navigate to Experiences**: Go to the _Experiences_ section and select the experience you wish to modify.
3. **Add Variants**: Add the relevant variants to the selected experience to apply the audience targeting.

---

### **Adding Audiences to A/B Testing**

1. **Short UID**: Each variant is assigned a unique identifier, known as the _short UID_.
2. **Usage in Personalization**: The short UID is utilized in the Personalize Edge SDK and Personalize API requests to target the correct variant during A/B testing.
